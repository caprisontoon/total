미리보기에서 채팅을 누르면 여기에 표시됩니다.

플랫폼 원본은 구조 예시(목업)입니다. 실제 필드는 개발팀 수집 결과로 확정합니다.

  • 지원 플랫폼: 유튜브, 트위치, 치지직, KICK, CHEAR. SOOP은 이번 범위에서 제외.
  • 경쟁력: 플랫폼별 등급 배지를 최대한 살리고, 투네이션 후원자 등급(VIP·VVIP·SVIP)을 플랫폼 구분 없이 붙인다.
  • 통합 시청자수: 플랫폼별 시청자수를 가져와 합산한다(필수).
  • 제외: 공지, 채팅 고정, 플랫폼 후원 표시, 명령어 제어 (서드파티 제약).
  • 투네이션 후원은 우리 데이터라 선택 옵션으로 포함. 16종을 메시지형·콘텐츠형·선택형·미션형으로 묶어(UI 설계서 v3.3 후원 탭의 입력 항목 기준) 한 줄·강조 줄·카드로 표시. 실서비스 기본값은 꺼짐 권장.
  • CHEAR 등급 체계는 가정값. 연동 문서로 확인 필요.
  • iframe 수집 방식은 미정.
